================================================================================
STRATEGY 1 — HIGHLY ACTIVE DAY STRATEGY
================================================================================

PURPOSE
-------
Trade high-momentum days: news-driven gaps, sustained directional moves, wide
opening ranges, high volume on index and options. Best when the market goes
into "high profit day" mode.

PIPELINE (4 stages, current implementation)
--------------------------------------------
Stage 1 — Buffer Filter (09:16:30 IST)
  * Take each index's Opening Range from the 09:15 1-min candle.
  * ATM reference = OR midpoint (A).
  * Strike window = ATM ± typical_buffer_points
       NIFTY ±300, SENSEX ±900 (configurable per index).
  * For each strike × {CE, PE}: resolve Upstox key, fetch 30 days of 1-min
    history, compute 9/21 EMA crosses.
  * Compute last-day's-last-cross inside the tail window
    (default 30 min before close).
  * Output:
      data/strategy/stage_1_initial/<TICKER>/<INDEX>/<strike>_<TYPE>/

Stage 2 — EMA Cross Isolation (09:17:00 IST)
  * For each Stage 1 contract, compute today's 09:15 first-candle cross.
  * Bullish-priority rules:
        last bearish + today bullish   -> isolate
        last bullish + today none      -> isolate
        last none    + today any       -> isolate
        both bullish                   -> isolate
        bullish + today bearish        -> isolate (bullish priority)
        bearish only (no bullish)      -> skip
        both bearish                   -> skip
        both none                      -> skip
  * CE/PE pairing: if one side isolates, copy BOTH sides of the strike
    to stage_2_isolation with decision = "isolate" / "isolate_paired".
  * Output:
      data/strategy/stage_2_isolation/<TICKER>/<INDEX>/<strike>_<TYPE>/

Stage 3 — R2 Activation Watcher (09:15 - 09:20 IST)
  * Background tracker polls live feed LTP every 1 second.
  * PER-CONTRACT basis: each contract judged against its OWN R2
    (from its OWN 09:15 1-min candle).
  * When contract's window high >= its own R2 -> activate.
  * Records: touch time, window high, gap, candles source.
  * Output:
      stage_3_r2_activated/
      stage_3_decisions.json  (per-contract audit tree)

Stage 4 — Order Selection & Placement (09:18 IST)
  * Read all Stage 3 activations.
  * Per index: keep N strikes nearest to ATM
       NIFTY: 3, SENSEX: 5 (configurable).
  * FIFO by R2-touch time across combined pool.
  * Final pick: 1.
  * Entry LTP rule:
       Live run     -> freshest live-feed LTP
       Catch-up run -> close of the option's own 1-min candle at or
                       before 09:18, drawn from a tape already sliced
                       AT THE SOURCE to [09:15, 09:20].
       No fallback to live LTP in catch-up mode.
  * Paper order only — real Upstox order API not wired.
  * Output:
      stage_4_order/<TICKER>/<INDEX>/orders.json
      order_meta_test.json

WHEN THIS STRATEGY IS EXPECTED TO WIN
-------------------------------------
  * Wide opening range (> typical buffer in points).
  * Sustained directional move in first 20 minutes.
  * High volume on index and on options.
  * News-driven / gap-open days.
  * R2 breaks happen early and cleanly.

KNOWN BEHAVIOUR
---------------
  * Runs on every startup, daily refresh, hard refresh.
  * Catch-up: if project starts after scheduled time but before 23:59 IST,
    stages replay with catchup=True and audit fields
    (execution_mode, scheduled_time_ist, actual_time_ist, post_market).
  * Paper orders only.
