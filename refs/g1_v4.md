**Document Version:** 4.1.0

## 1. Executive Summary & Core Architectural Premise

The cross-index relational foundation remains intact: any of the four indices touching $R3$ or $S3$ establishes the session's relational bias ($R3 \rightarrow \text{CE}$, $S3 \rightarrow \text{PE}$), and execution routing maps to a NIFTY 50 strike. The strike is chosen as the nearest round-50 strike to NIFTY spot LTP at the trigger millisecond.

v4.1 introduces branching behavior post-isolation based on whether the trigger originated internally from NIFTY 50 or externally from high-beta/correlated benchmark indices.

## 2. Multi-Index Priority Arbitration & Relational Mapping

### 2.1 Index Universe & Polling Configuration
The engine polls 2-second tick snapshots across four indices:

| Index Symbol | Instrument Key | Exchange | Segment | Priority Rank | Strike Step |

| `MIDCPNIFTY` | `NSE_INDEX\|NIFTY MID SELECT` | NSE | `NSE_INDEX` | **1** | 25 |
| `BANKNIFTY` | `NSE_INDEX\|Nifty Bank` | NSE | `NSE_INDEX` | **2** | 100 |
| `NIFTY` | `NSE_INDEX\|Nifty 50` | NSE | `NSE_INDEX` | **3** | 50 |
| `SENSEX` | `BSE_INDEX\|SENSEX` | BSE | `BSE_INDEX` | **4** | 100 |

### 2.2 Relational Isolation & Source Attribution
Priority tie-break:
$$\text{MIDCPNIFTY} \succ \text{BANKNIFTY} \succ \text{NIFTY} \succ \text{SENSEX}$$

Strike selection formula:
$$\text{NIFTY Strike} = \text{round}\left(\frac{\text{Current NIFTY Spot LTP}}{50}\right) \times 50$$

Path execution routing evaluates:
```json
{
  "trigger_index": "MIDCPNIFTY",
  "trigger_is_self_nifty": false
}
```
`trigger_is_self_nifty` is determined at isolation and immutable throughout the session.

## 3. End-to-End Execution Pipeline (Steps 1–11)

### Steps 1–7: Pre-Market to Isolation Alerts (Unchanged)
* **Step 1:** Pre-market opening range calculation at 09:16:10 for all indices $\rightarrow$ `data/index/<sym>/first_candle.json`.
* **Step 2:** Strike universe preparation for NIFTY weekly contracts.
* **Step 3:** Structural display pivots (`left=15, right=15`) for dashboard telemetry.
* **Step 4:** Multi-index boundary watch (2-second poll).
* **Step 5:** Relational strike isolation and opposite instrument pairing.
* **Step 6:** Persist state to `data/level_isolated_instrument.json`.
* **Step 7:** Telegram notification broadcast.

### Step 8: Branch on Trigger Source
```python
def step_8_branch_after_isolation(isolation_record):
    if isolation_record.trigger_is_self_nifty:
        return start_path_a_nifty_self_trigger(isolation_record)
    else:
        return start_path_b_external_trigger(isolation_record)
```

### Step 9A: NIFTY Self-Trigger Execution (Path A — Unchanged)
Executes when `trigger_is_self_nifty == True`:
* 10-minute scan window: $[T_{\text{touch}},\ T_{\text{touch}} + 10\text{ min}]$.
* Pivot scan: `left=15, right=3` on primary bias instrument.
* **Case 1 (Support):** BUY primary bias instrument.
* **Case 2 (Resistance):** BUY counter instrument (auto-reverse).
* **Case 3 (Both):** Support wins (BUY primary).
* **Case 4 (Timeout):** Halt (`blocked: window_expired_no_pivot`).
* **Step 10A:** Promotion sidecar written if counter side entered.
* Max one order per day.

---

### Step 9B: External Trigger Continuous SR Watch (Path B — New)
Executes when `trigger_is_self_nifty == False`:
* 10-minute scan window and auto-reverse are disabled.
* Primary bias instrument remains isolated for the full session.
* Post-isolation SR engine consumes confirmed levels on the bias instrument.

#### 9B.1 Monitored Instrument
Only the bias-side instrument (`isolation_record.primary_key`). The counter instrument is used exclusively as an execution destination.

#### 9B.2 Level Eligibility Matrix
A level $L$ is valid for order entry if and only if:
1. $L.\text{confirmed\_time\_fast} > \text{isolation\_record.touched\_at}$ (strictly post-isolation).
2. $L.\text{left\_bars} \ge \text{STRATEGY\_ENTRY\_PIVOT\_LEFT\_BARS}$ and $L.\text{right\_bars} \le \text{STRATEGY\_ENTRY\_PIVOT\_RIGHT\_BARS}$.
3. Deduplication key `(bias_instrument_key, L.type, round(L.price, 4), L.confirmed_time_fast)` is not in `placed_keys`.
4. `strategy_locked_today == False`.
5. Timestamp format is valid ISO-8601.

#### 9B.3 Routing Matrix
| Level Type Confirmed on Bias Side | Execution Target | Side |
| :--- | :--- | :---: |
| **Support** | Bias-side instrument | BUY |
| **Resistance** | Counter-side instrument | BUY |

#### 9B.4 Order Construction & Rules
```python
def build_path_b_order(level, isolation_record, bias_key, counter_key):
    if level.type == "support":
        target_key = bias_key
    else:
        target_key = counter_key

    lot = lot_size_for(target_key)
    if lot is None:
        return None  # Telemetry only, no execution

    entry_price, price_source = entry_price_for(target_key, level.confirmed_time_fast)
    if entry_price is None or entry_price <= 0:
        return {"status": "skipped", "reason": "no_entry_price"}

    stop_price, sl_pct, stop_pct, stop_source = compute_ltp_tier_stop(entry_price, target_key)
    target_level = pick_target_resistance(target_key, entry_price, level.confirmed_time_fast)

    return {
        "status": "armed",
        "instrument_key": target_key,
        "side": "BUY",
        "entry_price": entry_price,
        "entry_source": price_source,
        "entry_time": level.confirmed_time_fast,
        "stop_loss": stop_price,
        "sl_pct": sl_pct,
        "target": target_level.price if target_level else None,
        "target_time": target_level.confirmed_time if target_level else None,
        "lot_size": lot,
        "origin_level": {
            "instrument": bias_key,
            "type": level.type,
            "price": level.price,
            "pivot_time": level.pivot_time,
            "confirmed_time": level.confirmed_time_fast,
        },
        "path": "B_external_trigger",
    }
```

* **Entry:** Candle close at `level.confirmed_time_fast` (fallback: Live LTP).
* **Stop-Loss:** LTP-tier bracket ($5\%\text{--}15\%$).
* **Target:** Next confirmed resistance on target instrument with $\text{Price} > \text{Entry}$.
* **Lot Size:** NIFTY = 65, SENSEX = 20. Other symbols are telemetry-only.
* **Side:** Exclusively BUY.

#### 9B.5 Deduplication & Promotion Suppression
* Placed order keys are tracked in a session hash set `placed_keys`.
* Path B never triggers `apply_promotion()`. The bias-side instrument remains permanently active on dashboard views with a `Path B · Multi-Order` badge.

### Step 10B: Rupee-Based Profit Engine & Lockdown (Path B)

#### 10B.1 Profit Calculation
$$\text{Profit}_{\text{₹}} = (\text{Current LTP} - \text{Entry Price}) \times \text{Lot Size}$$

#### 10B.2 Activation of Profit Protection
Protection engages when:
1. $\text{peak\_profit\_rs} \ge \text{STRATEGY\_EXT\_PROFIT\_ACTIVATION\_RS}$ ($₹1,000$), **OR**
2. Instrument's $\text{Entry Price} < R2 \land \text{Current LTP} \ge R3$ (`STRATEGY_EXT_R3_BREAKOUT_ACTIVATION_ENABLED`).

Once triggered, state moves from `PRE_TRAIL` to `TRAILING`. Fixed Stop-Loss is superseded.

#### 10B.3 Trailing Stop Calculation
$$\text{lock\_rs} = \max(1000,\ \text{peak\_profit\_rs} - 500)$$
$$\text{Trailing Stop Price} = \text{Entry Price} + \frac{\text{lock\_rs}}{\text{Lot Size}}$$

| Peak Profit ($\text{₹}$) | Locked-in Gain ($\text{₹}$) | Trailing Stop Price |
| :---: | :---: | :---: |
| $< 1,000$ | — | Original Fixed SL |
| $1,000$ | $1,000$ | $\text{Entry} + 1000 / \text{lot}$ |
| $1,400$ | $1,000$ | $\text{Entry} + 1000 / \text{lot}$ |
| $1,500$ | $1,000$ | $\text{Entry} + 1000 / \text{lot}$ |
| $1,600$ | $1,100$ | $\text{Entry} + 1100 / \text{lot}$ |
| $2,000$ | $1,500$ | $\text{Entry} + 1500 / \text{lot}$ |
| $3,000$ | $2,500$ | $\text{Entry} + 2500 / \text{lot}$ |

The trailing stop ratchets upwards only.

#### 10B.4 Exit Priority Matrix
1. **Target Hit:** $\text{Current LTP} \ge \text{Target}$. Exits at target price $\rightarrow$ **Triggers Strategy Lockdown**.
2. **Trailing Stop:** $\text{Current LTP} \le \text{Trailing Stop Price}$ in `TRAILING` mode.
3. **Bearish Exit:** In `TRAILING` mode, if Bearish Regime triggers (see 10B.5).
4. **Initial SL:** $\text{Current LTP} \le \text{Initial SL}$ while in `PRE_TRAIL` mode.
5. **EOD Exit:** Clock time $\ge 15:30$ $\rightarrow$ market close on final bar.

#### 10B.5 Bearish-Regime Detection
Evaluates to `True` when at least 2 of 3 conditions match during active `TRAILING`:
1. Last $N$ ($N=2$) completed 1-minute bars on held contract are bearish ($\text{Close} < \text{Open}$).
2. NIFTY 50 Spot LTP drops below price at confirmed time of last primary support.
3. NIFTY 50 Spot prints $N$ ($N=2$) consecutive lower closes on 1-minute timeframe.

#### 10B.6 Lockdown Scope
When any Path B trade hits its target:
* Set `strategy_locked_today = True`.
* Cease evaluation of new SR levels.
* Existing open positions continue running their trailing stops and exits until completion.

## 4. Complete Decision Logic & Code Structure

```python
def process_path_b_on_level_confirmed(level, isolation_record, placed_keys, strategy_locked_today):
    if strategy_locked_today:
        return {"status": "locked"}

    if level.confirmed_time_fast <= isolation_record.touched_at:
        return {"status": "not_eligible", "reason": "pre_isolation"}

    dedup = (
        isolation_record.primary_key,
        level.type,
        round(level.price, 4),
        level.confirmed_time_fast
    )
    if dedup in placed_keys:
        return {"status": "dedup_skipped"}

    bias_key = isolation_record.primary_key
    counter_key = isolation_record.opposite_key
    target_key = bias_key if level.type == "support" else counter_key

    lot = lot_size_for(target_key)
    if lot is None:
        placed_keys.add(dedup)
        return {"status": "telemetry_only", "reason": "not_whitelisted"}

    entry_price, price_source = entry_price_for(target_key, level.confirmed_time_fast)
    if not entry_price or entry_price <= 0:
        return {"status": "skipped", "reason": "no_entry_price"}

    stop_price, sl_pct, _, _ = compute_ltp_tier_stop(entry_price, target_key)
    target_level = pick_target_resistance(target_key, entry_price, level.confirmed_time_fast)

    order = {
        "order_id": f"{target_key}|{level.type}|{level.confirmed_time_fast}",
        "path": "B_external_trigger",
        "dummy": True,
        "instrument_key": target_key,
        "side": "BUY",
        "entry_price": entry_price,
        "entry_source": price_source,
        "entry_time": level.confirmed_time_fast,
        "stop_loss": stop_price,
        "sl_pct": sl_pct,
        "target": target_level["price"] if target_level else None,
        "target_time": target_level["confirmed_time"] if target_level else None,
        "lot_size": lot,
        "origin_level": {
            "instrument": bias_key,
            "type": level.type,
            "price": level.price,
            "pivot_time": level.pivot_time,
            "confirmed_time": level.confirmed_time_fast,
        },
        "profit_state": "PRE_TRAIL",
        "peak_profit_rs": 0.0,
        "status": "OPEN",
    }
    placed_keys.add(dedup)
    return {"status": "armed", "order": order}


def process_path_b_on_tick(order, current_ltp, held_candles, nifty_ltp):
    if order["status"] != "OPEN":
        return

    lot = order["lot_size"]
    profit_rs = (current_ltp - order["entry_price"]) * lot
    order["peak_profit_rs"] = max(order["peak_profit_rs"], profit_rs)

    # Check Trailing Activation
    if order["profit_state"] == "PRE_TRAIL":
        r2 = or_levels_for(order["instrument_key"]).get("R2")
        r3 = or_levels_for(order["instrument_key"]).get("R3")
        
        reached_profit_target = order["peak_profit_rs"] >= STRATEGY_EXT_PROFIT_ACTIVATION_RS
        r3_breakout = (
            STRATEGY_EXT_R3_BREAKOUT_ACTIVATION_ENABLED
            and r2 is not None and r3 is not None
            and order["entry_price"] < r2
            and current_ltp >= r3
        )
        if reached_profit_target or r3_breakout:
            order["profit_state"] = "TRAILING"

    # Execution Priority
    if order["target"] and current_ltp >= order["target"]:
        close_order(order, "TARGET_HIT", order["target"])
        set_strategy_lockdown()
        return

    if order["profit_state"] == "TRAILING":
        trail = trailing_stop_price(order)
        if current_ltp <= trail:
            close_order(order, "TRAILING_STOP_HIT", trail)
            return

        if STRATEGY_EXT_BEARISH_EXIT_ENABLED and is_bearish_regime(
            order["instrument_key"], held_candles, nifty_ltp
        ):
            close_order(order, "BEARISH_EXIT", current_ltp)
            return
    else:
        if current_ltp <= order["stop_loss"]:
            close_order(order, "STOP_HIT", order["stop_loss"])
            return
```
