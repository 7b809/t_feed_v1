1 · Full global rule — one rule, two legs
Let option_type ∈ {"CE", "PE"} and define the direction-free ITM delta:

text
itm_delta = +Δ    if option_type == "CE"
itm_delta = −Δ    if option_type == "PE"
Then every PE statement maps 1-to-1 to CE:

Rule A — Delta trail (continuous, once active)
PE (as you wrote)	CE (mirror)	Unified
Trigger	Δ ≤ −0.60	Δ ≥ +0.60	itm_delta ≥ 0.60
On first fire	stop = max(stop, entry + 20)	identical	identical
Every subsequent completed candle	stop = max(stop, close − 15)	identical	identical
Ratchet	stop only goes up	identical	new_stop = max(prev_stop, candidates…)
Rule B — Gamma/Theta profit-jump (event trigger, may repeat)
PE	CE	Unified
Trigger	Δ ≤ −0.65 ∧ Θ > −38	Δ ≥ +0.65 ∧ Θ > −38	itm_delta ≥ 0.65 ∧ Θ > −38
Target	target += 15	identical	identical
Stop	stop = max(stop, close − 10)	identical	identical
Stacking	Yes — fires again on each qualifying candle	identical	store target_extension_count
Rule C — Vega-crush guard (per-candle veto on tightening)
PE	CE	Unified
Condition	(vega_entry − vega_now) / vega_entry > 0.25 ∧ itm_delta improving	identical	identical
Action	Block A's stop tightening for this candle only; B's target extension still allowed; trail resumes next candle	identical	identical
Note on C's "0.25": your spec literally says "drops > 0.25 from entry". If vega is quoted on a 10-25 absolute scale (typical NIFTY), that is a 25 % relative drop (≈ 6 points on an entry of 24). If your provider quotes vega on a 0.1-0.3 scale, it is an absolute 0.25 (which for typical entries never fires). I default to 25 % relative (VEGA_CRUSH_DROP_FRACTION=0.25) and flag this as item #1 in §8.

Scope guard (both rules)

if order.indicator != "supertrend": return          # SR orders never trail
if not config.dummy_supertrend_greek_trail_enabled: return
if candle is not completed: return                  # only completed candles

Commentary on what the PE run proves
A is a state, not an event. Once itm_delta ≥ 0.60 at 10:09, every subsequent candle trails to close − 15 — unless C vetoes.

B stacks and is independent of A. B fires at 10:09? — no, 10:09 Δ 0.603 < 0.65. B fires at 10:33, 10:40, 10:45, 11:00, 11:15 — five extensions = +75 cumulative, taking target 135 → 210.

C is a per-candle veto on A, not a lock. At 10:45–11:15 it froze A (stop stayed 158.75) because vega was crashing while Δ kept improving. At 11:30 Δ turned down, C released, A resumed and jumped the stop to 171.00. Winner was protected.

Profit floor (entry + 20 = 115) entered max(…) from the very first A fire — it is the safety net that never moves down.

7 · Full modified pseudocode for the engine
Drop this into app/services/dummy_order_engine.py. It slots in where the current PE-only block sits — I've marked the integration points.

python
# ---------- module-level helpers ----------------------------------------

def compute_itm_delta(option_type: str, delta: float | None) -> float | None:
    """Direction-free ITM delta: +Δ for CE, −Δ for PE."""
    if delta is None:
        return None
    return delta if option_type.upper() == "CE" else -delta


def apply_greek_trail(
    *,
    order: dict,
    candle: dict,
    config: "Settings",
    on_event: Callable[[dict], None],
) -> None:
    """
    Apply Rules A / B / C to a SUPERSTREND dummy order on a completed candle.
    No-op for SR orders, disabled flag, non-completed candles, or missing Δ.
    """
    # --- scope guards
    if order.get("indicator") != "supertrend":
        return
    if not config.dummy_supertrend_greek_trail_enabled:
        return
    if not candle.get("is_completed"):
        return

    greeks = candle.get("greeks") or {}
    delta  = greeks.get("delta")
    theta  = greeks.get("theta")
    vega   = greeks.get("vega")
    if delta is None:
        on_event({"type": "trail_skip", "reason": "delta_missing", "at": candle.get("close_ts")})
        return

    option_type = order["option_type"]                # "CE" or "PE"
    entry       = float(order["entry_price"])
    entry_vg    = float(order["entry_greeks"]["vega"])
    close       = float(candle["close"])

    itm_delta = compute_itm_delta(option_type, float(delta))
    prev_itm  = float(order.get("last_itm_delta") or compute_itm_delta(option_type, float(order["entry_greeks"]["delta"])))

    # --- Rule C precondition: vega crash AND delta improving
    vega_crash = (entry_vg - float(vega)) / entry_vg > config.greek_trail_vega_crush_drop_fraction if entry_vg else False
    delta_improving = itm_delta > prev_itm
    c_guard = vega_crash and delta_improving

    # --- Rule A: delta trail (state, per-candle)
    a_active = itm_delta >= config.greek_trail_delta_a

    # --- Rule B: gamma/theta profit-jump (event)
    b_fires = (
        itm_delta >= config.greek_trail_delta_b
        and theta is not None
        and float(theta) > config.greek_trail_theta_b_floor
    )

    # --- compute new stop: max of {prev, profit floor, A trail, B trail}
    candidates = [float(order["stop_price"]), entry + config.greek_trail_profit_floor_points]
    if a_active and not c_guard:
        candidates.append(close - config.greek_trail_trail_a_points)
    if b_fires and not c_guard:
        candidates.append(close - config.greek_trail_trail_b_points)
    new_stop = max(candidates)

    # --- Rule B target extension — allowed even under C
    new_target = float(order["target_price"])
    if b_fires:
        new_target += config.greek_trail_target_jump_points
        order["target_extension_count"] = int(order.get("target_extension_count", 0)) + 1

    # --- persist + audit
    order["last_itm_delta"] = max(prev_itm, itm_delta)   # monotone watermark
    if new_stop > float(order["stop_price"]) or new_target > float(order["target_price"]):
        order["stop_price"]   = new_stop
        order["target_price"] = new_target
        order.setdefault("trail_jumps", []).append({
            "at":        candle.get("close_ts"),
            "close":     close,
            "itm_delta": itm_delta,
            "theta":     theta,
            "vega":      vega,
            "a":         a_active,
            "b":         b_fires,
            "c":         c_guard,
            "new_stop":  new_stop,
            "new_target": new_target,
        })
        on_event({
            "type": "trail_jump",
            "order_id": order.get("order_id"),
            "new_stop": new_stop,
            "new_target": new_target,
            "a": a_active, "b": b_fires, "c": c_guard,
        })

8 · Open flags — confirm before merge
#	Flag	Recommendation
1	C's "0.25" units — absolute vs 25 % relative?	I default to 25 % relative (VEGA_CRUSH_DROP_FRACTION=0.25). If your provider's vega is on the 0.1-0.3 scale, flip to absolute and set threshold 0.25 directly. Confirm which.
2	C blocking A vs both A and B	My impl blocks A only, B target extension always fires. If C should also block B, change one line: if b_fires and not c_guard: candidates.append(...) → if b_fires: candidates.append(...) and skip the new_target += under C.
3	C persistent vs per-candle	My impl is per-candle (re-evaluated every candle). In the PE run, C fired 10:45–11:15 and released at 11:30 when Δ stopped improving. Confirm that's the intent.
4	B re-fires when Δ worsens	In the PE run, B fired at 10:40 even though itm_delta fell from 0.6849 to 0.6750, because B has no monotone requirement. If B should require monotone improvement, add and itm_delta > prev_itm.
5	Profit floor applied before A first fires	My impl includes entry + 20 in max(...) from the very first candle — so even before A activates, if close − 15 > entry + 20, stop could exceed the floor. In practice A and the profit floor coincide on the A-fire candle. Confirm.
6	Entry greeks availability	Entry greeks must be captured at entry time from live_feed_state_store. If they're missing for a leg, we should not start the trail (trail_unavailable_no_entry_greeks event) rather than fall back to zeros.
7	option_type source of truth	Derived from strike_option ("25400_pe" → pe) or persisted explicitly. I persist explicitly on order creation — cheaper and less error-prone.
8	θ sign convention	Your spec assumes negative θ = time decay (so "less negative is better"). Some feeds send θ as positive decay. The engine must normalise before comparing to THETA_B_FLOOR = −38. Add a THETA_IS_POSITIVE_DECAY env flag if your feed flips.
9	Dashboard version bump	"greek_trail_version": "1.0" → "1.1" in three places. Stored historical orders tagged "1.0" remain interpretable.
10	Restart behaviour	My impl rebuilds nothing from candles — stop_price, target_price, last_itm_delta, target_extension_count are read from the persisted order. Verify dummy_order_store.py and dummy_order_mongo_store.py round-trip these fields.
