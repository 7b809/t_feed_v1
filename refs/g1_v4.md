## 1. Executive Summary & Core Architectural Premise

### 1.1 The Operational Concept
The G1 v3.2 engine monitors major Indian market indices for extreme opening-range boundary exhaustion ($R3$ ceiling / $S3$ floor). 

While multiple indices serve as market-wide boundary triggers, **all options execution is concentrated strictly in NIFTY 50 options** to guarantee institutional-grade liquidity, minimal bid-ask slippage, and tight tick responsiveness.

## 2. Multi-Index Priority Arbitration Matrix

### 2.1 Monitored Index Universe
The system maintains active live tick feeds and level tracking for four core index assets from `index_instruments.json`:

| Index Instrument Key | Trading Symbol | Exchange | Segment | Priority Rank | Default Step Size |
| :--- | :--- | :--- | :--- | :---: | :---: |
| `NSE_INDEX\|Nifty 50` | `NIFTY` | NSE | `NSE_INDEX` | **1 (Top)** | 50 |
| `NSE_INDEX\|Nifty Bank` | `BANKNIFTY` | NSE | `NSE_INDEX` | **2** | 100 |
| `NSE_INDEX\|NIFTY MID SELECT` | `MIDCPNIFTY` | NSE | `NSE_INDEX` | **3** | 25 |
| `BSE_INDEX\|SENSEX` | `SENSEX` | BSE | `BSE_INDEX` | **4** | 100 |

### 2.2 Arbitration Rules for Boundary Touches
1. **First-Touch-Isolates:** The first index to touch either its pre-calculated $R3$ or $S3$ level triggers the system isolation routine.
2. **Deterministic Tie-Break:** If multiple index touches arrive within the same 2-second polling window:
   $$\text{NIFTY} \succ \text{BANKNIFTY} \succ \text{MIDCPNIFTY} \succ \text{SENSEX}$$
3. **Execution Routing Target:** Regardless of which index fired the touch trigger (even if triggered by `BANKNIFTY` or `MIDCPNIFTY`), the system **immediately queries the live tick price of NIFTY 50** and isolates the corresponding **NIFTY strike**.
4. **Single Isolation Lockdown:** Once any index touch is resolved and NIFTY is isolated, all subsequent touches on all other indices are logged as `already_isolated` and ignored for the remainder of the session (`STRATEGY_ENTRY_ONLY_ONCE_PER_DAY = true`).

## 3. End-to-End Execution Pipeline (Steps 1 to 11)

### Step 1: Pre-Market Opening Range & Boundary Formulation (09:16:10 AM)
* Calculate $H, L, A, D\_H, D\_L, R1, S1, R2, S2, R3, S3$ for all 4 monitored indices:
  * NIFTY 50
  * BANKNIFTY
  * MIDCPNIFTY
  * SENSEX
* Persist calculated boundary thresholds to `data/index/<index_symbol>/first_candle.json`.

### Step 2: Strike Filter Generation (09:16:15 AM)
* Generate strike universes for NIFTY 50 derivatives.
* Round up for Call options: $\lceil R_x / 50 \rceil \times 50$.
* Round down for Put options: $\lfloor S_x / 50 \rfloor \times 50$.
* Persist to `data/level_instruments.json`.

### Step 3: Background SR Engine (Continuous 15-Bar Display Tracking)
* Background pivot scanner continues running `left=15, right=15` across all active series for display on `/isolated`, charting cards, and Telegram broadcasts.

### Step 4: Multi-Index Boundary Watch (09:16:15 – 15:30:00)
* Evaluate ticks every 2 seconds across the 4 indices against their respective $R3$ and $S3$ threshold values:
  ```python
  touches = []
  for index in [NIFTY, BANKNIFTY, MIDCPNIFTY, SENSEX]:
      if index.ltp >= index.R3:
          touches.append({"index": index.name, "boundary": "R3", "bias": "CE", "priority": index.priority})
      elif index.ltp <= index.S3:
          touches.append({"index": index.name, "boundary": "S3", "bias": "PE", "priority": index.priority})

  if touches and not is_already_isolated():
      # Sort by priority ascending (1 is highest priority)
      touches.sort(key=lambda x: x["priority"])
      winning_touch = touches[0]
      trigger_isolation(winning_touch)
  ```

### Step 5: NIFTY Strike Resolution & Directional Bias
* **Directional Bias:** Inherited directly from the winning touch:
  * Touch on $R3 \implies \mathbf{Bias = CE}$
  * Touch on $S3 \implies \mathbf{Bias = PE}$
* **Strike Selection:** Read current `NIFTY 50` spot LTP at the trigger millisecond:
  $$\text{Isolated Strike} = \text{round}\left(\frac{\text{NIFTY\_LTP}}{50}\right) \times 50$$
* **Isolated Pair:** Both `NIFTY <Strike> CE` (Bias) and `NIFTY <Strike> PE` (Counter) are loaded into memory.

### Step 6 & 7: Snapshot Capture & Isolation Persistence
* Snapshot the trigger index state, NIFTY spot state, and option metrics.
* Write atomic record to `data/level_isolated_instrument.json`.
* Dispatch Telegram alert: `[Level Isolation] Triggered by <INDEX> <BOUNDARY> -> NIFTY <STRIKE> Locked`.

### Step 8: Post-Isolation Dual Tracking Initialization
* Open dedicated in-memory price buffer for the isolated NIFTY CE and PE contracts.
* Start the 10-minute entry window timer:
  $$W = [\text{touch\_time},\ \text{touch\_time} + 10\text{ minutes}]$$

### Step 9: Fast Pivot Scan, S/R Prioritization & Auto-Reverse Engine
Recomputed every 10 seconds. Scans the isolated NIFTY contracts with fast pivot settings (`left=15, right=3`):

1. **Dual Scan on Bias Side:** Check for both `fast_supports` ($S$) and `fast_resistances` ($R$) forming in window $W$.
2. **Prioritization Gate:**
   * **Case 1: Both $S$ and $R$ confirm on Bias Side:** Support takes priority. Arm the **Bias Side** on Support bounce.
   * **Case 2: Fast Support ($S$) confirms alone on Bias Side:** Arm the **Bias Side** on Support bounce.
   * **Case 3: Fast Resistance ($R$) confirms alone on Bias Side (No Support):** 
     $$\mathbf{TRIGGER\ AUTO\text{-}REVERSE}$$
     * Cancel bias-side watch.
     * Switch immediately to the **Counter Side (PE if bias was CE; CE if bias was PE)**.
     * Take entry price as the **live LTP of the counter instrument** at the exact confirmation instant of the bias resistance.
     * Mark `entry_type = "auto_reverse_on_rejection"`.
   * **Case 4: Buffer Window $W$ expires without valid confirmation:**
     * State $\rightarrow$ `blocked: all_candidates_in_window_blocked`.

### Step 10: Promotion & Daily Lockdown
* Lock the winning armed instrument into `data/level_isolated_instrument_promotion.json`.
* Mark strategy as `EXECUTED_FOR_DAY`. All further signals blocked.

### Step 11: Order Placement & LTP-Tier Risk Enforcement
* Compute stop-loss using the deterministic LTP-tier table.
* Calculate profit target at the next structural resistance.
* Format and send order payload to broker API (`/admin/orders/buy`).

## 4. Decision Logic & Pseudo-Code

```python
def evaluate_strategy_step_9(isolation_record, nifty_candles_bias, nifty_candles_counter):
    touch_time = isolation_record.touch_time
    window_end = touch_time + timedelta(minutes=STRATEGY_ENTRY_BUFFER_MINUTES)
    now = current_time()

    # Fast scan: left=15, right=3
    fast_s = scan_fast_pivots(nifty_candles_bias, left=15, right=3, kind="SUPPORT", window=(touch_time, window_end))
    fast_r = scan_fast_pivots(nifty_candles_bias, left=15, right=3, kind="RESISTANCE", window=(touch_time, window_end))

    # -------------------------------------------------------------------------
    # RULE 1: SUPPORT CONFIRMED (Priority over Resistance if both exist)
    # -------------------------------------------------------------------------
    if len(fast_s) > 0:
        S = fast_s[0]
        if S.confirmed_time_fast > now:
            return {"state": "waiting_confirmation", "side": isolation_record.bias_side}

        entry_price = get_candle_close(nifty_candles_bias, S.confirmed_time_fast) or get_live_ltp(isolation_record.bias_instrument_key)

        # Sanity Guard
        if entry_price < S.price:
            log_event("WARN", f"Entry price {entry_price} below support {S.price}. Blocked.")
            return {"state": "blocked", "reason": "entry_below_support"}

        stop, stop_pct, sl_pct = compute_ltp_tier_stop(entry_price)
        target = find_next_resistance(nifty_candles_bias, entry_price)

        log_event("INFO", f"ARMED BIAS: {isolation_record.bias_side} at {entry_price}, Stop: {stop} ({stop_pct*100:.1f}%)")
        return {
            "state": "armed",
            "side": isolation_record.bias_side,
            "entry_type": "bias_support_bounce",
            "entry_price": entry_price,
            "stop": stop,
            "stop_pct": stop_pct,
            "target": target,
            "chosen": True
        }

    # -------------------------------------------------------------------------
    # RULE 2: ONLY RESISTANCE CONFIRMED -> AUTO-REVERSE
    # -------------------------------------------------------------------------
    elif len(fast_r) > 0 and len(fast_s) == 0:
        R = fast_r[0]
        if R.confirmed_time_fast > now:
            return {"state": "waiting_confirmation", "side": isolation_record.counter_side, "note": "awaiting_reversal"}

        counter_side = "PE" if isolation_record.bias_side == "CE" else "CE"
        counter_key = isolation_record.counter_instrument_key
        
        # Real-time live tick entry on counter strike
        counter_entry_price = get_live_ltp(counter_key)
        
        if not counter_entry_price or counter_entry_price <= 0:
            return {"state": "blocked", "reason": "invalid_counter_price"}

        stop, stop_pct, sl_pct = compute_ltp_tier_stop(counter_entry_price)
        target = find_next_resistance(nifty_candles_counter, counter_entry_price)

        log_event("INFO", f"AUTO-REVERSE FIRED: Bias {isolation_record.bias_side} rejected at {R.price}. "
                          f"Buying {counter_side} at live LTP {counter_entry_price}. Stop: {stop}")

        return {
            "state": "armed",
            "side": counter_side,
            "entry_type": "auto_reverse_on_rejection",
            "reversal_trigger": {
                "bias_resistance_price": R.price,
                "bias_resistance_time": R.pivot_time,
                "confirmed_time_fast": R.confirmed_time_fast
            },
            "entry_price": counter_entry_price,
            "stop": stop,
            "stop_pct": stop_pct,
            "target": target,
            "chosen": True
        }

    # -------------------------------------------------------------------------
    # RULE 3: TIMEOUT
    # -------------------------------------------------------------------------
    if now > window_end:
        log_event("INFO", "10-minute buffer window expired with no tradeable confirmation.")
        return {"state": "blocked", "reason": "all_candidates_in_window_blocked"}

    return {"state": "scanning", "reason": "waiting_for_pivot"}
```

## 5. Deterministic LTP-Tier Stop-Loss Framework

$$Stop = \text{round\_down\_to\_tick}(\text{entry\_price} \times (1 - sl\_pct))$$

```
Entry LTP Bracket       sl_pct    Sample Entry    Calculated Stop    Risk Amount
────────────────────────────────────────────────────────────────────────────────
LTP < ₹100               15%         ₹75.00           ₹63.75           ₹11.25
₹100 <= LTP < ₹200       12%        ₹150.00          ₹132.00           ₹18.00
₹200 <= LTP <= ₹300      10%        ₹250.00          ₹225.00           ₹25.00
LTP > ₹300                5%        ₹400.00          ₹380.00           ₹20.00
```

* **Tick Round-Down Rule:** Stops are rounded down to the nearest 0.05 tick interval to avoid premature exits during spread noise.
* **Safety Clamp (`STRATEGY_MAX_STOP_PCT = 0.35`):** Any calculated stop distance exceeding 35% is clamped to 35% with an immediate system warning log.
